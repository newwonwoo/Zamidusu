# 독자 시험 (검증 V-22) — 개선 전·후 해설을 같은 질문으로 읽혀 비교

**누가 읽었나**: 사람이 아니라 **별도의 AI 에이전트 3명**입니다. 각자 “자미두수·사주를 거의 모르는 40대 직장인” 역할로, 이 폴더의 입력 파일 하나만 읽고 도구 없이 답했습니다.
**한계**: AI 독자는 실제 사람의 어려움을 그대로 보여 주지 못합니다. 개선 전·후를 **상대 비교**하는 용도이며, 사람 5명 이상의 사용성 시험은 피드백 단계의 제안으로 남깁니다(05-feedback.md).

## 방법
- 5문항: 시나리오 T6(남, 1990-01-30 12시)의 명궁·관록궁·재백궁, 다른 명반(여, 1991-09-05 8시)의 부처궁·질액궁.
- 문항마다 **같은 칸의 개선 전 글과 개선 후 글**을 가·나로 보여 줍니다. 어느 쪽이 새 글인지는 알려 주지 않았고, 독자마다 가·나 배정을 달리해(`reader-key.json`) 순서 효과를 상쇄했습니다.
- 글: 개선 전은 커밋 `6a91282` 의 코드로, 개선 후는 시험 직전 코드로 **화면과 같은 순서·같은 용어 풀이**로 옮겼습니다(전체 개선 전 글은 `../explain-before-6a91282.md`). 시험 뒤 화면에 반영한 변경(삼합·대궁 설명 줄, 별 카드 속 사주 용어 줄 접기, ‘N개’ 설명)은 이 시험에 들어 있지 않습니다.
- 질문 3개(Q1~Q3, 글만으로 답할 수 있는 사실)와 핵심 요약, 모르는 낱말, 쉬운 정도(1~5), 더 쉬운 쪽 선택.

## 채점표(사람이 채점, 0~2점)
- 2점: 글이 말하는 정답을 분명히 답함 / 1점: 일부만 맞거나 글에서 ‘중심 별’을 직접 말하지 않아 **추정해서** 답함 / 0점: 답하지 못함(“글에서 알 수 없음”).
- Q1 “이 칸의 중심 별과 장점·성격”, Q2 “별의 힘(밝기) 또는 조심할 점”, Q3 “사주 쪽이 말하는 뜻”(명궁은 일간의 성향, 부처궁은 배우자 신호, 질액궁은 부족한 오행과 몸 부위, 관록궁은 일하는 방식, 재백궁은 재물 기운).
- Q3 은 개선이 **새로 넣은 정보**(개수의 뜻)를 묻는 문항이라 개선 후에 유리합니다. 그래서 Q1·Q2(양쪽 글에 모두 있는 사실)와 Q3 을 따로 적습니다.

### 시험에서 나온 남은 어려움과 그 뒤 조치
- “삼합”(11회)·“대궁”(9회)은 개선 전·후 **모두** 가장 많이 모르는 말이었다 → 화면의 “함께 읽는 칸” 줄 아래에 한 줄 설명을 추가.
- 별 카드의 “사주 대응”(건록·역마·신살·고진·과숙 등)을 모른다는 지적 → 본문 흐름을 끊지 않도록 **접어서**(“사주와 같은 점 보기”) 두었다.
- “‘3개’가 무엇을 센 것인지” → “해설 읽는 법”에 “N개는 사주의 여덟 글자 중 그 기운에 해당하는 글자의 수” 항목을 추가.
- ‘함’이라는 단계 이름 자체, 홍란·고진·과숙 같은 별 이름, 甲申 같은 간지 표기는 그대로 남아 있다(별 이름·간지는 명반에 그대로 보이는 어휘).
- 독자 2는 서로 다른 명반의 문항을 한 사람의 글로 보고 “연간이 다르다”고 지적했다. 시험 설계(문항마다 다른 사람이라는 안내가 약했음)의 문제이며 해설의 오류가 아니다.
