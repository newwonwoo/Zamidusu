## 1. 재현·개선 원칙

| 구분 | 의미 | 검증 방법 |
|---|---|---|
| 동일 재현 | 사이트가 맞게 동작하는 부분은 화면 구성·규칙·결과를 그대로 만든다 | 같은 입력을 사이트와 재구현에 넣어 칸 단위로 비교 |
| 개선 | 사이트가 틀린 부분은 고친다. 항목마다 번호(I-xx) | 사이트와 달라지는 칸은 모두 I-xx로 설명되어야 한다. 번호 없는 차이는 결함 |
| 보완/신규 | 사이트에 없는 기능 (N-xx) | 신규 요건으로 따로 검증 |

- **원본 호환 모드**: 검증 전용 스위치. 개선을 끄고 사이트 오류까지 따라 해서 사이트와 비교 시험을 반복할 수 있게 한다. 사용자에게는 개선판만 보인다.
- **저작물 구분**: 규칙·배치·구조·기능은 동일 재현. 해설 문구·로고·이미지·스타일시트 코드는 복제하지 않고 새로 작성.

## 2. [화면구조]

```
자미두수 명반 (단일 화면)
├ 입력부
│  ├ 기본 입력 → 명반 보기
│  │   성별, 양/음력, 평/윤달, 생년·월·일, 시(모름 포함)·분, 출생지, 연도 기준(신규)

│  ├ 운 선택: 본명 → 대한 → 유년 → 유월 → 유일 → 유시
│  ├ 궁 칸: 주성·밝기 / 사화 / 길성·살성 / 잡성 / 12신 계열 / 대한·유년 나이 / 궁명+간지
│  ├ 가운데: 명반 요약 + 달력 기준 알림(신규)
│  └ 삼방사정 표시 (본궁 · 삼합 · 대궁)
├ 우측 패널 (탭)
│  ├ (명반-궁 해설): 요약표 · 주성 없는 궁 안내(개선) · 조합 해설(개선) · 별 해설(새 문안)
│  └ (명반-사주 비교) 신규: 달력 차이표 · 연도 기준 선택 · 공통점 · 차이점 · 교차 보기(2단계)
├ 부가 기능: (팝) 글꼴 설정 / 이미지 저장 / (팝) 만세력 / 음성 읽기 / 표시 옵션
└ 모바일: 탭 3개 (명반 · 궁 해설 · 사주 비교)
```

목업: 캔버스 「자미두수 재구현 화면 목업」 (메인 · 사주 비교 탭 · 모바일 · 명반 격자 부품 4장). 표시된 명반은 시험 입력 T6(1990-01-30 12시 남)이다.

## 5. 사주명리 비교 근거표

각 항목은 코드로 검증했거나 자료를 인용했다. 검증 방법을 같이 적는다.

### 공통점

| 번호 | 내용 | 근거 |
|---|---|---|
| C-1 | 같은 뿌리: 천간·지지·음양오행 | 위키백과 (두 체계가 같은 기반을 쓴다고 명시) |
| C-2 | 10년 운의 방향 규칙이 같음 (연간 음양 + 성별) | 1984-01-30(음년 남) 역행 확인, 사이트·iztro 일치 |
| C-3 | **녹존 = 연간의 건록, 천마 = 연지 기준 역마, 천괴·천월 = 연간 기준 천을귀인** | 코드 검증: 1930~2020년 91개 연도 모두 일치 |
| C-4 | 12운성 이름을 함께 씀 (자미두수의 포태 12신) | 사이트 화면의 '포태 12신' 표기 |
| C-5 | 삼방사정은 삼합 두 칸 + 충 칸 | 화면 스크립트 (R-04) |

### 차이점

| 번호 | 내용 | 근거 |
|---|---|---|
| D-1 | 달력: 사주는 24절기, 자미두수는 음력 월·일. 같은 생일에도 연·월이 다를 수 있음 | T6: 사주 己巳年 丁丑月, 자미두수 庚午年 정월. 사주는 2개 라이브러리(lunar-javascript, sxtwl) 일치 3건 |
| D-2 | 같은 이름, 다른 규칙: 문창은 사주=일간 기준 귀인(乙→午), 자미두수=태어난 시 기준(午시→辰) | 자미두수 쪽은 T6 명반에서 확인(辰). 사주 문창귀인 표는 전통 표 인용(코드 미검증) |
