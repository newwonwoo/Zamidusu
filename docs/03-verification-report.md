쉬운 해설 개선에서도 **검사 도구의 결함**이 나왔다. ① 전문용어 목록이 일반 낱말과 섞여 오탐(‘소한’ ← 사소한, ‘화기’ ← 소화기, ‘충’ ← 충돌, ‘대한’ ← “선하게 대한”) → 낱말 경계로 잡는 목록과 부분 일치 목록으로 분리. ② 전수 검사가 157초 걸려 CI 에 부담 → 같은 문장 캐시와 의미 없는 반복 제거로 6초. ③ 샘플 문서의 서식 검사가 빈 줄·들여쓰기를 이중 공백으로 셈 → 줄 단위 검사. ④ 독자 시험의 설계 한계 — 독자 2 가 서로 다른 사람의 명반을 한 사람의 것으로 보고 “연간이 다르다”고 지적했다(해설의 오류가 아니라 시험 안내 부족).

## 7. 성능과 크기

- 명반 + 사주 + 비교 데이터 계산(`computeOutcome`, 무작위 150건, 로컬 컨테이너): 한국 기준 평균 46ms(p95 61ms, 최대 183ms), 중국 기준 평균 48ms(p95 66ms). 운 뷰 2개(대한+유년) 평균 40~46ms. 궁 해설 12개 평균 1.1ms(p95 2.0ms, 최대 7.5ms — 한눈에 보기가 더해져 0.8ms 에서 늘었음). 역산(3개 값) 1.4ms. E2E 에서 “명반 보기” 클릭부터 화면 갱신까지 1초 이내.
- 배포물: `dist/index.html` + JS 한 파일 1.2MB(gzip 398KB). 대부분이 iztro·lunar 계열 라이브러리다. 한국 음력 표는 2.6KB.

## 9. 검증하지 못한 것과 한계

1. **원본 사이트와의 직접 대조는 하지 못했다.** 비교 근거는 원장의 관찰 기록과 독립 구현뿐이다. 사이트의 음력 기준(한국/중국)·득/리 매핑·역산 동작 등이 이에 해당한다. 사용자가 사이트에서 몇 건을 대조해 주면 가장 값싸게 닫을 수 있다(05-feedback.md).
2. **한국천문연구원 원자료를 직접 열람하지 못했다.** 그 자료에서 만들어진 공개 라이브러리(범위 ~2050-12-31)와 대조했다. 2051~2100년은 같은 규칙의 계산값이고, 1912년 이전은 중국 음력과 같다는 표의 사실을 따랐다.
3. **브라우저는 Chromium 계열(로컬 + GitHub 의 Chrome)만** 확인했다. Firefox·Safari 는 미확인. 모바일은 390px 에뮬레이션이며 실기기는 아니다.
4. **음성 읽기**는 재생이 시작되거나 불가 안내가 뜨는 것까지만 확인했다(헤드리스 환경에 음성 엔진이 없음).
5. **해설 문장의 명리적 타당성**은 자동 검사 대상이 아니다. 문장 길이·전문용어 표시·되풀이·구조·반응성만 검사한다. 전통 이론에 따른 서술이며 통계로 검증된 것이 아니다(화면에도 그렇게 표기). 전문가 감수는 하지 않았다. **쉬운 말로 바꾸는 과정에서 전통 해석의 뜻이 달라지지 않았는지도 전문가가 확인하지 못했다**(문안은 개발자가 새로 쓴 것).
6. **유년~유시 운의 정확도(U-02)** 는 엔진 값 그대로이고, 운의 경계(입춘 등)는 날짜 단위다.
7. **절기 시각**은 lunar-javascript 값이며 독립 천문식(정확도 약 15분)과의 대조에서 최대 13.9분 이내로 일치한다. 한국천문연구원이 발표한 절기 시각표와는 대조하지 못했다 — 절입 시각 몇 분 이내의 출생은 월주·연주가 발표값과 어긋날 수 있다.
8. 접근성은 자동 검사(axe)와 키보드 조작 확인까지다. 스크린 리더로 직접 읽어 보지는 않았다. 사용성(실제 사용자 평가)은 하지 않았다.
9. 해외 출생지는 대표 도시 25곳과 경도 직접 입력이며, 1908년 이전의 표준시 이력은 시간대 데이터가 주는 값을 따른다.
10. **“쉽다”는 자동 검사로 보증되지 않는다.** 자동 검사는 문장 길이·전문용어 표시·되풀이·구조만 본다. 독자 시험(V-22)은 AI 독자 3명이고 채점도 개발자가 했으며, 시험 뒤에 고친 세 가지(삼합·대궁 설명, 사주 대응 접기, ‘N개’ 설명)는 다시 시험하지 않았다. 낱말 자체의 어려움(‘함’, 홍란·고진·과숙, 甲申 같은 간지)은 남아 있다.
11. **분량은 늘었다**(칸 해설 평균 954자 → 1,289자). 사용자 결정(“분량 무관”)에 따른 것이지만, 맨 앞의 “한눈에 보기”만 읽어도 결론을 알 수 있게 한 구조에 기댄 결정이다.
12. 교차 보기 2단계(N-05)는 여전히 만들지 않았다. 사주 쪽 문장은 범주의 일반 의미(개수의 뜻)까지만 말하며, 두 체계의 신호가 같은지 다른지는 판정하지 않는다.
