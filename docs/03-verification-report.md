### V-15 한국 음력 (I-15, 신규) — 합격 · 21건
- **한국천문연구원 자료 기반 라이브러리**(`korean-lunar-calendar`, 개발 전용)와 1900-02-01~2050-12-31 의 **55,121일 전수 일치**(양력→음력). 음력→양력도 모든 날짜가 일치하고, 윤달이 있는 해와 윤달 번호(1901~2049)가 일치.
- 생성기를 처음부터 다시 돌려 저장된 표(`lunarkr-data.ts`)와 비교 → 동일(표가 낡거나 손으로 고쳐지지 않았음).
- 생성기를 **중국 표준시로** 돌리면 lunar-javascript 와 1961~2099 의 50,769일이 모두 일치 → 합삭·중기·윤달 규칙 구현이 맞다는 독립 증거.
- 1912년 이전은 중국 음력과 같다(한국천문연구원 표가 그렇다): 4,351일 불일치 0.
- 구조: 달이 끊김 없이 이어짐(29·30일), 해마다 12·13개월, 윤달 ≤ 1, 정월 초하루가 1월 21일~2월 21일, 1900-01-31~2101-01-28 의 73,412일이 음력 하나에 대응하고 양력으로 정확히 되돌아옴.

### V-16 입춘 순간 판정 (A-3, 신규) — 합격 · 8건
절입 전후 아홉 지점(−25시간~+25시간) × 25개 연도(1952~2048) = 225건에서 명반 연주 = 사주 연주 = 기대값, 임의 시각 3,000건에서 `ipchunYearOf` = lunar-javascript 정밀 연주. 고정 사례: 2024 입춘(한국 17:27) 전후, 한국/중국 날짜가 어긋나는 2021 입춘(한국 2월 3일 23:59). 번들에서도 같은 결과(E2E 10항목). 패치가 계산 후 해제됨(예외 후 포함).

### V-17 접근성·반응형 (신규) — 합격
axe-core 29개 상태 위반 0(색 대비·랜드마크·제목 순서·표 머리글·폼 레이블 포함). 키보드로 칸 선택(Enter)·팝업 닫기(Esc) 확인. 화면 폭 1920·1440·1181(3열)과 1180·1024·900·820·761(2열)에서 배치·칸 겹침·가로 넘침 점검, 760px 이하는 3탭.

### V-18 개인정보·배포 (신규) — 합격
- 외부/비-GET 요청 0(E2E 전 흐름). 공유 링크는 해시(#)에 담기고, 복사한 링크를 열었을 때 **서버가 받은 요청 주소에 생년월일시가 없음**을 서버 쪽에서 확인(예전 쿼리 형식은 서버에 보임을 같이 확인해 감시 장치가 헛돌지 않음을 증명).
- `dist/index.html` 을 **파일로 직접 열어도**(file://) 명반·스타일·이미지 저장이 동작, 하위 경로(`/Zamidusu/`) 호스팅도 동작.
- GitHub Actions(ubuntu-latest, 새 환경)에서 `npm ci` → audit → 타입 검사 → 테스트 → 빌드 → E2E 전 단계 성공.

## 9. 검증하지 못한 것과 한계

1. **원본 사이트와의 직접 대조는 하지 못했다.** 비교 근거는 원장의 관찰 기록과 독립 구현뿐이다. 사이트의 음력 기준(한국/중국)·득/리 매핑·역산 동작 등이 이에 해당한다. 사용자가 사이트에서 몇 건을 대조해 주면 가장 값싸게 닫을 수 있다(05-feedback.md).
2. **한국천문연구원 원자료를 직접 열람하지 못했다.** 그 자료에서 만들어진 공개 라이브러리(범위 ~2050-12-31)와 대조했다. 2051~2100년은 같은 규칙의 계산값이고, 1912년 이전은 중국 음력과 같다는 표의 사실을 따랐다.
3. **브라우저는 Chromium 계열(로컬 + GitHub 의 Chrome)만** 확인했다. Firefox·Safari 는 미확인. 모바일은 390px 에뮬레이션이며 실기기는 아니다.
4. **음성 읽기**는 재생이 시작되거나 불가 안내가 뜨는 것까지만 확인했다(헤드리스 환경에 음성 엔진이 없음).
5. **해설 문장의 명리적 타당성**은 자동 검사 대상이 아니다. 길이·구조·반응성·중복만 검사한다. 전통 이론에 따른 서술이며 통계로 검증된 것이 아니다(화면에도 그렇게 표기). 전문가 감수는 하지 않았다.
6. **유년~유시 운의 정확도(U-02)** 는 엔진 값 그대로이고, 운의 경계(입춘 등)는 날짜 단위다.
7. **절기 시각**은 lunar-javascript 값이며 독립 천문식(정확도 약 15분)과의 대조에서 최대 13.9분 이내로 일치한다. 한국천문연구원이 발표한 절기 시각표와는 대조하지 못했다 — 절입 시각 몇 분 이내의 출생은 월주·연주가 발표값과 어긋날 수 있다.
8. 접근성은 자동 검사(axe)와 키보드 조작 확인까지다. 스크린 리더로 직접 읽어 보지는 않았다. 사용성(실제 사용자 평가)은 하지 않았다.
9. 해외 출생지는 대표 도시 25곳과 경도 직접 입력이며, 1908년 이전의 표준시 이력은 시간대 데이터가 주는 값을 따른다.
