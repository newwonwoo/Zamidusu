## 2. 이 확인서가 보증하는 것과 보증하지 않는 것

**보증한다**: 같은 입력에서 명반·사주 값이 독립 구현·외부 자료·천문 공식과 일치한다는 것(범위는 검증 보고서), 입력 검증·화면 동작·접근성·개인정보(외부 전송 없음)가 위에 적은 수준이라는 것, 사이트와의 차이가 번호로 설명된다는 것.
**보증하지 않는다**: 원본 사이트와의 일치(직접 대조하지 못함), 해설의 명리적 정확성·통계적 타당성(전통 이론에 따른 참고용이며 화면에도 그렇게 적었다), **해설이 실제 사람에게 쉽게 읽히는지**(자동 검사와 AI 독자 시험까지만 했다), 한국천문연구원 원자료와의 직접 일치(공개 라이브러리로 대조), Firefox·Safari·실기기 동작, 스크린 리더 사용성.

## 4. 사용 조건과 알려진 한계

1. **음력 기준**: 기본은 한국 음력(한국천문연구원 방식)이다. 사이트·iztro 계열 도구와 값을 맞추려면 입력부에서 “중국”을 고른다. 두 기준이 다른 날짜(1900~2050년 중 3.59%)에는 화면이 다른 기준의 날짜를 함께 보여 준다. **2051~2100년은 같은 규칙의 계산값**이고 1912년 이전은 중국 음력과 같다.
2. **독립 검증의 범위**: 독립 구현이 대조하는 별은 52개(주성 14, 보좌·살성, 월·일·시·년지 계열 잡성)다. 그 밖의 일부 잡성(천관·천복·천주·비렴·파쇄 등)과 박사·장전·세전 12신은 엔진(iztro) 값이며 별도로 독립 검증하지 않았다. 장생12신은 시작 위치만 확인했다.
3. **운 모드**: 유년·유월·유일·유시는 엔진 값이고(U-02), 운의 경계(입춘 등)는 날짜 단위다.
4. **절기 시각**: lunar-javascript 값이다. 독립 천문식과 최대 13.9분 이내로 맞지만 한국천문연구원 발표값과는 대조하지 못했다. 절입 시각 몇 분 이내의 출생은 월주·연주가 발표값과 어긋날 수 있다.
5. **해설**: 전통 이론에 따른 참고용이다. 건강·재무·법률 판단을 대신하지 않는다. 문장 길이·전문용어 표시·되풀이·구조는 자동 검사하지만 내용의 타당성은 사람이 봐야 하고, **쉬운 말로 바꾸는 과정에서 전통 해석의 뜻이 달라지지 않았는지도 전문가가 확인하지 못했다**.
6. **호환 모드**의 출생지 보정·대한 궁 이름·음력 기준은 사이트를 보지 못해 원장의 기술을 따른 **추정 재현**이다.
7. **환경**: 검증은 Chromium 계열에서 했다. 음성 읽기는 브라우저에 한국어 음성이 있을 때만 동작한다.
8. **의존성 패치**: 명반 엔진의 하위 라이브러리(`lunar-lite@0.2.8`) 파일 5개를 설치 직후 덮어쓴다(해시 검증, `patches/README.md`). `npm install --ignore-scripts` 로 설치하면 타입 검사·테스트가 바로 실패해 알려 준다.
9. **쉬운 해설의 검증 한계**: 독자 시험은 **AI 독자 3명**이고 채점은 개발자가 했다. 시험 뒤에 고친 세 가지(삼합·대궁 설명 줄, 별 카드 속 사주 대응 접기, ‘N개’ 설명)는 다시 시험하지 않았다. 낱말 자체의 어려움(‘함’, 홍란·고진·과숙 같은 별 이름, 甲申 같은 간지 표기)은 남아 있다. 해설 분량은 늘었다(칸당 평균 954자 → 1,289자).
